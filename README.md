# Lending Club 신용평가 모델

SNU KDT 13기 5조 | 김도형·김은규·노현선·박채원·변수민·한윤주


Lending Club 데이터로 장기적으로 건전하게 운용 가능한 신용평가 모델 개발. 단순 부도 예측이 아니라 **IRR(수익률)이 국채 수익률을 상회하는 대출을 선별**하는 것이 목표이며, 평가 지표로 **Sharpe Ratio**(위험 대비 수익률)를 활용한다.

<br>

## 레포지토리 구조


```
├── preprocessing/    표본 정의·X 전처리·y(수익률)계산·변수 선택
│   └── README.md     전처리 파이프라인 상세 설명, 실행 방법
├── modeling/         모델링 실험 (선형·트리·효과분해·최종평가)
│   └── README.md     노트북 구성, 핵심 결과
```

전체 흐름: **전처리(표본 정의·변수 선택) → 모델링(선형/트리 실험 → 효과 분해·컷오프 확정 → 최종 test 평가)** 

- 전처리 코드와 설계 근거(누출 차단, vintage 편향 통제 등)확인 → `preprocessing/README.md`
- 모델 성능·실험 결과 확인 → `modeling/README.md`

<br>


## 파이프라인 요약

```
표본 정의·6:2:2 분할 → X 전처리(train fit → transform) → y(IRR·초과수익) 계산
→ 변수 선택(47열 통제칸 / 122열 전체)
→ 모델링: 선형×47 / 트리×47 / 트리×122 실험
→ 모형효과·변수효과 분해 → 챔피언 모델(CatBoost×122) 확정
→ 승인 컷오프(45%) 선정 → 공식 test 데이터로 최종 1회 평가
```

<br>

## 핵심 결과

| 실험 | 모델 | 변수 | val Sharpe |
|---|---|---|---|
| ① 선형×47 | K-means+Ridge (k=7) | 47열 | 0.1717 |
| ② 트리×47 | CatBoost | 47열 | 0.1921 |
| ③ 트리×122 | CatBoost | 122열 | **0.1940** |

<br>
챔피언 모델(CatBoost×122)은 공식 test(744,443건)에서 Sharpe +0.1164를 기록했으며, LC의 기존 sub_grade 기준선(+0.0425)을 상회한다. 자세한 수치와 해석은 `modeling/README.md` 및 `modeling/04_final_test.ipynb`에서 확인 가능.
